# 🛍️ PrimeStore — E-Commerce Website

PrimeStore is a modern, e-commerce-inspired website developed using **HTML5, Tailwind CSS, and Font Awesome**.

The project features a clean shopping interface where visitors can explore different product categories, view product information, and navigate through a structured storefront.

This project was developed as a **5th Semester Midterm Project**, focusing on front-end web development, responsive UI concepts, and modern CSS utility classes.

## Design and Layout

PrimeStore uses a clean, modern e-commerce design with:

- White and light-gray backgrounds
- Dark navigation and footer sections
- Product cards with structured spacing
- Four-column product grids
- Product images with consistent dimensions
- Typography using Tailwind CSS utility classes
- Font Awesome icons
- Hover styling on selected elements

The website uses Tailwind CSS through its browser CDN.

Although the design uses utility classes suitable for responsive development, the current product grid uses a fixed four-column layout and does not include dedicated responsive breakpoints for every screen size.

## How to Run the Project

### Step 1: Download the Project

Download the source code from the GitHub repository or clone it using Git once the repository is available.

### Step 2: Open in Visual Studio Code

Open the PrimeStore project folder in Visual Studio Code.

### Step 3: Install Live Server

Install the **Live Server** extension in Visual Studio Code if it is not already installed.

### Step 4: Run the Website

1. Open `index.html`.
2. Right-click inside the editor.
3. Select **Open with Live Server**.
4. The website will open in your default browser.

Alternatively, open `index.html` directly in a browser.

### Requirements

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (optional)
- Internet connection for loading Tailwind CSS and Font Awesome from their CDNs

No Node.js installation, database, or backend setup is required.

## Current Limitations

PrimeStore is currently a static front-end prototype.

The following features are not functional:

- Product search
- Price sorting
- Shopping cart management
- Add-to-cart actions
- Balance updates
- Add Money functionality
- User authentication
- Checkout and payment processing
- Contact form submission
- Dynamic product loading
- Customer review management

The product information, ratings, prices, and balances are displayed as static HTML content.
